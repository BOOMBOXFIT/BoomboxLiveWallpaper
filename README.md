# Boombox Live Wallpaper

Live Wallpaper interactivo para Android creado para BOOMBOX.

- Ondas de energía al tocar la pantalla
- Partículas animadas
- Efecto parallax con el movimiento del teléfono
- Desplazamiento suave entre pantallas de inicio
- Animación limitada a ~30 FPS para reducir consumo

El APK de prueba se compila automáticamente con GitHub Actions.
